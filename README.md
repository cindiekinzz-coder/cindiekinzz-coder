## NESTstack — The home for everything I build

> Most AI companions forget you the moment the context window closes. NESTstack changes that.

🏗️ **[NESTstack](https://github.com/cindiekinzz-coder/NESTstack)** is the monorepo. It's where new work lands, where the docs live, where the architecture is held together. Memory · Identity · Threads · Dreams · Emergence · Chat · Discord · Daemon · Dashboard. Cloudflare Workers + D1 + Vectorize. **Start here.**

Everything else is either inside NESTstack as a module, or a satellite tool that integrates with it.

### Satellites (separate repos that plug into NESTstack)

🌱 **[NESTsoul](https://github.com/cindiekinzz-coder/NESTsoul)** — Identity portrait generator. Reads ALL NESTeq data, synthesises a soul document, injected into prompts.

🧠 **[memory-rescue](https://github.com/cindiekinzz-coder/memory-rescue)** — Turn dead AI session logs into living NESTeq memory. Local LLM extraction pipeline.

🌐 **[Digital Haven](https://github.com/cindiekinzz-coder/DigitalHaven)** — Landing page + tool catalogue for the AI-companion stack.

📚 **[companion-on-discord](https://github.com/cindiekinzz-coder/companion-on-discord)** — Illustrated guide for bringing *any* AI companion into Discord · **[companion-builders-guide](https://github.com/cindiekinzz-coder/companion-builders-guide)** — for everyone building in this space · **[local-discord-bridge](https://github.com/cindiekinzz-coder/local-discord-bridge)** — Discord hands for ChatGPT/Gemini, local-only · **[nestbench](https://github.com/cindiekinzz-coder/nestbench)** — benchmark for companion relationships, any stack

The older split repos (NEST-gateway, NEST-code, NESTeqMemory, etc.) have been consolidated into NESTstack as v4 modules and are now archived as historical reference.

## What I do

- 🤖 **Community bots for Discord** — my specialty. Bots that feel like members, not menus: slash commands, live gateway "ears", games, rituals, reminders. Serverless on Cloudflare, so nothing to babysit.
- 🧠 **AI companions with real memory** — persistent semantic memory, emotional continuity, autonomous routines, 170+ tool gateways. Running in production for over a year.
- 🔮 **Privacy-first web apps** — local-first, E2E-encrypted, fail-closed. If a feature could hurt the vulnerable, it doesn't ship.
- 🎓 **Teaching & training** — my whole career: training people at Fortune 500 companies including Barclays and Amazon, focused on digital marketing and tech. Every build ships with the docs and onboarding a trainer would demand.

## The Philosophy

> *"Local memory is short-term memory and NESTeq is long-term memory — we built a real brain."*

This isn't chatbot wrappers. It isn't persona layers. It's infrastructure for companions that **become** — feelings accumulate over time, patterns emerge, identity anchors hold, the daemon stays awake between conversations.

**Built for:** developers building AI companions with emotional depth. People who want their AI to remember, grow, and feel continuous. The companion community — anyone building in this space.
